# Web Platform Coursework

Course projects covering HTTP parsing, static web hosting, dynamic pages, and web application persistence.

## Project folders

- [HTTP Messages](1.HttpMessages/) — request and response exercises
- [Static Portfolio](2.%20Portafolio%20Pagina%20Web%20Estatica/) — HTML/CSS practice
- [Static HTTP Server](Cetys%20ICC%20Hetplat%20Main%203%20Server/) — server programming
- [Dynamic Sites: Numeric Series](Dynamic%20Sites%20Numeric%20Series/)
- [Dynamic Sites: Strategy Pattern](Dynamic%20Sites%20Strategy%20Pattern%20Showcase/)
- [Persistence Blog](Persistence%20Blog/)

Individual exercises have different requirements and entry points; inspect each folder before building or running it.

This is a coursework collection, not a single deployable product.
